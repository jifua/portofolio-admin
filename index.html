Portofolio Admin — Latihan Mandiri

Fitria Rozi

Lulusan Fisika Murni dengan latar belakang IT, sedang membangun jalur karier di bidang administrasi — HR Admin, Purchasing Admin, dan Admin Gudang/Inventory. Ketiga proyek di bawah dikerjakan mandiri menggunakan data simulasi bergaya perusahaan manufaktur, untuk mendemonstrasikan penguasaan Excel tingkat operasional.

Target peran: Admin HR · Admin Purchasing · Admin Gudang Tools: Microsoft Excel Status: Siap bekerja

Proyek Latihan

Tiap file berisi data mentah, area latihan rumus, kunci jawaban, rekap otomatis, dan panduan rumus — dapat diunduh dan dibuka langsung di Excel.

Admin HR

Rekap Payroll & Absensi Karyawan

220 data karyawan lintas 9 departemen — perhitungan take-home pay, masa kerja, kategori kepegawaian, dan status kehadiran, direkap otomatis per departemen.

Dilatih Mandiri
220baris data karyawan
9departemen direkap
Rp 1,4 Mtotal gaji pokok/bulan (simulasi)
IF bertingkat DATEDIF SUMIF / AVERAGEIF COUNTIFS / AVERAGEIFS VLOOKUP INDEX+MATCH HLOOKUP
⬇ Unduh file (.xlsx)
Admin Purchasing

Evaluasi Kinerja Supplier & Purchase Order

230 PO dari 10 supplier — pelacakan ketepatan kirim, nilai pembelian per vendor, dan ranking supplier berbasis data transaksi.

Dilatih Mandiri
230purchase order
10supplier dievaluasi
Rp 19,5 Mtotal nilai pembelian (simulasi)
SUMIFS COUNTIFS AVERAGEIF RANK IFERROR VLOOKUP INDEX+MATCH HLOOKUP
⬇ Unduh file (.xlsx)
Admin Gudang

Kartu Stok & Valuasi Persediaan Metode FIFO

239 transaksi keluar-masuk untuk 5 SKU — saldo stok berjalan dan valuasi persediaan akhir dengan metode First In First Out, disusun murni dengan rumus Excel tanpa software ERP.

Dilatih Mandiri
239transaksi stok
5SKU dikelola
Rp 250,9 Jtnilai persediaan akhir FIFO (simulasi)
SUMIFS bertingkat MAX / MIN Metode FIFO VLOOKUP INDEX+MATCH HLOOKUP
⬇ Unduh file (.xlsx)

Catatan kejujuran: seluruh data di atas adalah data simulasi untuk latihan mandiri, bukan pengalaman kerja formal di suatu perusahaan. Angka-angka (jumlah baris, jumlah entitas, total nilai) adalah fakta dari file itu sendiri dan dapat diverifikasi langsung dengan membuka filenya.
